# Webshooter – 3D-Ansicht

Live: https://kilian0805.github.io/webshooter/

## Neues Modell hinzufügen
1. Datei in den Ordner `modelle` hochladen (auf github.com: Ordner öffnen → „Add file“ → „Upload files“).
2. Fertig. Nach ca. 1 Minute steht sie auf der Seite oben in der Auswahl.

Erlaubt: Webshooter-Pakete von Claude (`.json`, alle Funktionen), eigene Teile als `.stl`, `.obj`, `.glb`.
Der Dateiname wird zum Namen in der Auswahl (`webshooter-mk2.json` → „Webshooter MK2“).
Das Modell mit dem höchsten Namen (z. B. MK2 vor MK1) wird beim Öffnen zuerst angezeigt.
Direkt-Link zu einem Modell: `…/webshooter/#webshooter-mk1`

`modelle/liste.json` ist nur eine Reserve, falls GitHub die Ordnerliste mal nicht liefert.
